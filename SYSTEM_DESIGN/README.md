## 🎯 Learning Paths

### For Beginners (0-2 years experience)
**Duration**: 4-6 weeks
1. **Week 1**: [Introduction](./introduction.md) → [Fundamentals](./fundamentals/fundamentals.md)
2. **Week 2**: [Scalability](./scalability/scalability.md) → [Load Balancing](./load_balancing/load_balancing.md)
3. **Week 3**: [Databases](./databases/databases.md) → [Caching](./caching/caching.md)
4. **Week 4**: [Reliability](./reliability/reliability.md) → [Security](./security/security.md)
5. **Week 5-6**: [Case Studies](./case_studies/case_studies.md) and practice

### For Intermediate Developers (2-5 years experience)
**Duration**: 3-4 weeks
1. **Week 1**: [Scalability](./scalability/scalability.md) → [Microservices](./microservices/microservices.md)
2. **Week 2**: [Database Design](./databases/databases.md) → [Reliability](./reliability/reliability.md)
3. **Week 3**: [Security](./security/security.md) → [Case Studies](./case_studies/case_studies.md)
4. **Week 4**: Practice system design interviews

### For Senior Engineers (5+ years experience)
**Duration**: 2-3 weeks
1. **Week 1**: Review [Scalability](./scalability/scalability.md) and [Reliability](./reliability/reliability.md) patterns
2. **Week 2**: Deep dive into [Case Studies](./case_studies/case_studies.md)
3. **Week 3**: Practice complex system design scenarios

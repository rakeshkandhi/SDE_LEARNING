# Databases in System Design

Databases are essential for storing and retrieving data efficiently. This section covers types of databases, data modeling, consistency, and choosing the right database for your system.

## Types of Databases
- **Relational (SQL):** Structured data, strong consistency
- **NoSQL:** Flexible schema, high scalability

## Data Modeling
Design tables/collections to optimize queries and storage.

## Example
Use SQL for financial transactions, NoSQL for social media feeds.

## Best Practices
- Choose database based on use case
- Normalize data where possible

# Caching Overview

This document provides an overview of caching in system design, including its importance, benefits, and general concepts. For detailed techniques, see the respective files in this folder.

## What is Caching?
Caching is a method of storing frequently accessed data in a temporary storage area to improve performance and reduce load on backend systems.

## Benefits
- Improved performance
- Reduced latency
- Lower backend load
- Cost efficiency

## Types of Caching
- Client-side
- Server-side
- CDN
- Database
